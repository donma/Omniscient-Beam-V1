# Cyber Security Prompt

## 樣板一句話定位
適合資安服務、SOC 監控與企業安全顧問的資料信任型網站。

## 適合產業
資安服務、SOC 監控、企業安全顧問

## 不適合產業
餐飲、美妝等生活風格產業。

## 視覺方向
深藍黑、科技網格、資料儀表板。

## 色彩策略
深色底搭配青色強調，營造科技信任感。

## 版型策略
Dashboard / Data 信任型。

## Hero Pattern
dashboard-data-hero

## Navigation Pattern
top-navigation-mobile-drawer

## Content Rhythm
metrics-features-cases-cta

## 圖片風格要求
科技、抽象、資安相關圖片。

## 圖片數量要求
每套至少 25 張圖片或視覺素材。

## 12 頁內容定位
涵蓋首頁、解決方案、特色、詳情、案例、評價、FAQ、Demo、流程、觀點、文章、聯絡。

## SEO 關鍵字策略
資安、SOC、威脅偵測、事件應變、企業安全。

## CTA 策略
預約 Demo、聯絡。

## RWD 規則
桌機多欄、平板雙欄、手機單欄；手機使用漢堡選單。

## 可替換內容
品牌名稱、圖片、文案、聯絡資訊、色彩。

## 禁止事項
本樣板不是一般 Hero + 三卡片 + FAQ + CTA 的公版結構。

## 與相似樣板的差異說明
以資料儀表板與信任指標為核心，不同於沉浸式或目錄型。
